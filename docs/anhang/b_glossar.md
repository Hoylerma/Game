# Anhang B – Glossar

Historische Fachbegriffe und Spielbegriffe (Spielbegriffe sind mit ◆ markiert).

| Begriff | Erklärung |
|---|---|
| **Ablösung** | Abgeltung bäuerlicher Lasten (Dienste, Abgaben) gegenüber dem Grundherrn durch Geld oder Land im Zuge der Bauernbefreiung |
| **Agenda 2010** | Reformprogramm der Bundesregierung ab 2003 (Arbeitsmarkt, Sozialsysteme) |
| **Akzise** | Verbrauchssteuer, besonders in Städten der Frühen Neuzeit |
| **Allgemeines Landrecht** | Preußisches Gesetzbuch von 1794 |
| **Altes Reich** | Das Heilige Römische Reich Deutscher Nation (bis 1806) |
| **Aufarbeitung** ◆ | Spielsystem für den Umgang mit vergangenen Verbrechen; erzeugt internationales Vertrauen |
| **Auftragstaktik** | Führungsprinzip: Ziel vorgeben, Ausführung den Unterführern überlassen |
| **Außerparlamentarische Opposition (APO)** | Protestbewegung der 1960er-Jahre außerhalb des Parlaments |
| **Bauernlegen** | Einziehen von Bauernstellen durch Gutsherren, v. a. in Mecklenburg und Pommern |
| **Bizone / Trizone** | Wirtschaftlicher Zusammenschluss der amerikanischen und britischen (und später französischen) Besatzungszone |
| **Blankoscheck** | Bedingungslose Unterstützungszusage an Österreich-Ungarn im Juli 1914 |
| **Blockparteien** | Zugelassene Parteien in der DDR, die der Führung der SED folgten |
| **Bruchstelle** ◆ | Historischer Umbruch, an dem das Spiel einen Perspektivwechsel anbietet |
| **Bundesrat** | Länderkammer – im Kaiserreich (1871–1918) und in der Bundesrepublik (ab 1949) |
| **Bundesversammlung** | 1816–1866 Gesandtenkongress des Deutschen Bundes; ab 1949 Wahlgremium des Bundespräsidenten |
| **Burgfrieden** | Innenpolitische Waffenruhe der Parteien zu Beginn des Ersten Weltkriegs |
| **Chronik** ◆ | Automatisch erzeugtes Geschichtsbuch einer Partie |
| **Chronik-Skript** ◆ | Skriptsprache für Inhalte und Mods |
| **Corpus Evangelicorum / Catholicorum** | Zusammenschluss der evangelischen bzw. katholischen Reichsstände im Reichstag |
| **Deutsche Frage** | Frage nach Form, Grenzen und Ordnung eines deutschen Staates |
| **Dolchstoßlegende** | Behauptung, das deutsche Heer sei 1918 „im Felde unbesiegt“ von der Heimat verraten worden |
| **Domänen** | Staatliche Landgüter; wichtige Einnahmequelle der Fürsten |
| **Dreiklassenwahlrecht** | Preußisches Wahlrecht 1849–1918, das Wähler nach Steuerleistung in drei Klassen teilte |
| **Durchdringung** ◆ | Tatsächliche Herrschaftspräsenz des Staates in einem Ort |
| **Edikt** | Erlass eines Herrschers |
| **Emergente Front** ◆ | Front, die aus Truppendichte und Feuerkraft von selbst entsteht |
| **Erbuntertänigkeit** | Persönliche Bindung von Bauern an die Gutsherrschaft (u. a. Schollenpflicht, Gesindedienst) |
| **Ermächtigungsgesetz** | Gesetz vom 23. März 1933, das der Regierung Gesetzgebungsgewalt ohne Parlament gab |
| **Föderalismus** | Ordnungsprinzip, nach dem Gliedstaaten eigene Staatlichkeit innerhalb eines Gesamtstaates besitzen |
| **Fokus-Nation** ◆ | Staat mit eigenen Missionsbäumen und Inhalten |
| **Freistaat** | Bezeichnung für Länder ohne Monarchie (ab 1918), heute Bayern, Sachsen, Thüringen |
| **Fürstenbund** | Bündnis deutscher Fürsten unter preußischer Führung (1785) gegen die Pläne Josephs II. |
| **Gastarbeiter** | Angeworbene ausländische Arbeitskräfte in der Bundesrepublik (1955–1973) |
| **Generalstab** | Planungsstab der Armeeführung; in Preußen ab den Reformen nach 1806 prägend |
| **Gleichschaltung** | Ausschaltung und Unterordnung von Ländern, Verbänden und Institutionen unter das NS-Regime |
| **Grundherrschaft / Gutsherrschaft** | Zwei Formen der ländlichen Herrschaft: Abgaben der Bauern (westlich der Elbe) bzw. Eigenwirtschaft des Gutsherrn mit Frondiensten (östlich der Elbe) |
| **Gründerzeit** | Wirtschaftsboom nach 1871, endete im Gründerkrach 1873 |
| **Hallstein-Doktrin** | Politik der Bundesrepublik (1955–1969), mit Staaten, die die DDR anerkannten, keine Beziehungen zu unterhalten |
| **Hanse** | Bund norddeutscher Kaufleute und Städte; letzter Hansetag 1669 |
| **Hypothek** ◆ | Dauerhafte Belastung des Vermächtnisses durch historische Verbrechen |
| **Indemnität** | Nachträgliche Entlastung einer Regierung durch das Parlament (Preußen 1866) |
| **Innere Führung** | Leitbild der Bundeswehr: der „Staatsbürger in Uniform“ |
| **Interessengruppe** ◆ | Organisierte gesellschaftliche Kraft mit politischen Forderungen |
| ***itio in partes*** | Getrennte Beratung der Konfessionsparteien im Reichstag in Religionsfragen |
| **Junker** | Ostelbischer adliger Gutsbesitzer |
| **Kameralismus** | Deutsche Form der Staats- und Wirtschaftslehre des Absolutismus |
| **Kantonsystem** | Preußisches Rekrutierungssystem (ab 1733) mit festen Aushebungsbezirken |
| **Kontribution** | Grundsteuer auf dem Land in der Frühen Neuzeit; auch Kriegsabgabe |
| **Kräfte-Raum-Verhältnis** ◆ | Verhältnis von Truppenstärke zu Frontlänge, aus dem Bewegungs- oder Stellungskrieg entsteht |
| **Kulturkampf** | Konflikt zwischen preußischem Staat bzw. Reich und katholischer Kirche (1871–1887) |
| **Kurfürst** | Fürst mit dem Recht, den römisch-deutschen König zu wählen |
| **Landstände** | Vertretung von Prälaten, Ritterschaft und Städten gegenüber dem Landesherrn |
| **Länderfinanzausgleich** | Ausgleich der Finanzkraft zwischen den Ländern (seit 2020 über die Umsatzsteuerverteilung) |
| **Lastenausgleich** | Umverteilung zugunsten von Vertriebenen und Kriegsgeschädigten (1952) |
| **Lesezeichen** ◆ | Vordefiniertes Startdatum |
| **Matrikularbeiträge** | Beiträge der Bundesstaaten an das Kaiserreich |
| **Mediatisierung** | Verlust der Reichsunmittelbarkeit kleiner Herrschaften (v. a. 1803/1806) |
| **Milieu** | Sozialmoralische Lebenswelt mit eigenen Organisationen und Parteibindung (nach M. Rainer Lepsius) |
| **Mittellage** | Geopolitische Lage Deutschlands in der Mitte Europas |
| **Montanunion** | Europäische Gemeinschaft für Kohle und Stahl (1951/52) |
| **Normaljahr** | Stichjahr 1624 für den konfessionellen Besitzstand nach dem Westfälischen Frieden |
| **Notverordnung** | Verordnung des Reichspräsidenten nach Art. 48 der Weimarer Verfassung |
| **Ostpolitik** | Entspannungspolitik gegenüber Osteuropa und der DDR (ab 1969) |
| **Personalunion** | Mehrere Staaten mit demselben Herrscher |
| **Peuplierung** | Staatlich geförderte Ansiedlung von Menschen |
| **Polykratie** | Nebeneinander konkurrierender Machtzentren im NS-Staat |
| **Präsidialkabinett** | Regierung, die sich auf den Reichspräsidenten statt auf eine Parlamentsmehrheit stützte (1930–1933) |
| **Regime-KI** ◆ | KI, die den NS-Staat steuert; nicht vom Spieler kontrollierbar |
| **Reichsdeputationshauptschluss** | Beschluss von 1803 zur Neuordnung des Reiches (Säkularisation, Mediatisierung) |
| **Reichskreis** | Regionale Gliederung des Alten Reiches (zehn Kreise) |
| **Reichsritterschaft** | Reichsunmittelbarer niederer Adel ohne Sitz im Reichstag |
| **Reichsstadt** | Stadt, die direkt dem Kaiser unterstand |
| **Reichsstand** | Mitglied des Reichstags mit Sitz und Stimme |
| **Reservatrechte** | Sonderrechte einzelner Bundesstaaten im Kaiserreich (v. a. Bayern, Württemberg) |
| **Rezess** | Vertrag oder Vergleich, z. B. zwischen Fürst und Ständen |
| **Römermonat** | Rechnungseinheit für Reichssteuern im Alten Reich |
| **Rückhalt** ◆ | Politisches Kapital einer Regierung |
| **Runder Tisch** | Gesprächsforum von Regierung und Opposition in der DDR 1989/90 |
| **Säkularisation** | Enteignung kirchlicher Herrschaften (v. a. 1803) |
| **Schuldenbremse** | Verfassungsregel zur Begrenzung der Neuverschuldung (2009) |
| **Soziale Marktwirtschaft** | Wirtschaftsordnung der Bundesrepublik: Markt mit sozialem Ausgleich |
| **Sozialistengesetz** | „Gesetz gegen die gemeingefährlichen Bestrebungen der Sozialdemokratie“ (1878–1890) |
| **Sperrklausel** | Mindeststimmenanteil für den Einzug ins Parlament (z. B. 5 %) |
| **Stunde Null** | Bezeichnung für den Neuanfang 1945 |
| **Subsidien** | Zahlungen einer Macht an eine andere, oft für Truppen |
| **Systemwettbewerb** ◆ | Wettstreit von BRD und DDR um Attraktivität |
| **Tolerierung** | Unterstützung einer Minderheitsregierung ohne Koalition |
| **Treuhandanstalt** | Anstalt zur Privatisierung der volkseigenen Betriebe (1990–1994) |
| **Trias** | Politik der Mittelstaaten als dritte Kraft neben Preußen und Österreich |
| **Uhrwerk** ◆ | Name des Simulationskerns |
| **Verfassungskonvent** ◆ | Spielmodus zur Ausarbeitung einer Verfassung |
| **Vermittlungsausschuss** | Gremium von Bundestag und Bundesrat zur Einigung bei Gesetzen |
| **Vertrauensfrage** | Antrag des Kanzlers, ihm das Vertrauen auszusprechen (Art. 68 GG) |
| **Volksbegehren / Volksentscheid** | Instrumente direkter Demokratie |
| **Vormärz** | Zeit vor der Märzrevolution 1848 |
| **Wahlkapitulation** | Vertrag, den ein Kaiser vor seiner Wahl mit den Kurfürsten schloss |
| **Wandel durch Annäherung** | Leitformel der Ostpolitik (Egon Bahr, 1963) |
| **Wehrhafte Demokratie** | Prinzip des Grundgesetzes, sich gegen Verfassungsfeinde zu schützen |
| **Weltbühne** ◆ | Vereinfachte Simulation der Welt außerhalb Deutschlands |
| **Wendepunkt** ◆ | Inszenierte historische Entscheidungsszene |
| **Wirtschaftswunder** | Wirtschaftlicher Aufschwung der Bundesrepublik in den 1950er- und 1960er-Jahren |
| **Zeitgeist** ◆ | Europaweite Ideenströmungen, die Politik und Gesellschaft beeinflussen |
| **Zollverein** | Zollunion deutscher Staaten ab 1834 |
| **Zweitstimmendeckung** | Seit der Wahlrechtsreform 2023: Wahlkreissieger erhalten nur dann ein Mandat, wenn es durch die Zweitstimmen gedeckt ist |
| **Zwei-plus-Vier-Vertrag** | Vertrag von 1990 zwischen BRD, DDR und den vier Siegermächten über die äußeren Aspekte der Einheit |
