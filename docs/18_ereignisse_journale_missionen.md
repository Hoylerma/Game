# 18 – Ereignisse, Journale & Missionen

## 1. Inhaltstypen

| Typ | Vorbild | Funktion | Zielmenge |
|---|---|---|---|
| **Ereignisse** | EU, Victoria, CK | Historische, dynamische und atmosphärische Situationen mit Entscheidungen | ca. 3.500 |
| **Entscheidungen** | EU, Victoria | Vom Spieler auslösbare Aktionen mit Bedingungen | ca. 400 |
| **Epochen-Journale** | Victoria (Journal Entries) | Große Ziele und Prozesse einer Epoche | 8 Haupt- und ca. 70 Themenjournale |
| **Missionsbäume** | EU | Nationale Ziele mit Belohnungen | ca. 60 Fokusbäume + 15 generische Bäume |
| **Wendepunkte** | HOI-Fokus, CK-Entscheidungen | Inszenierte historische Schlüsselmomente | ca. 70 |
| **Krisen** | Victoria | Mehrstufige, eskalierende Prozesse | ca. 40 |
| **Chronik und Lexikon** | eigenes System | Geschichtsbuch der Partie und Hintergrundwissen | ca. 1.500 Lexikonartikel |

## 2. Anatomie eines Ereignisses

| Bestandteil | Beschreibung |
|---|---|
| **Titel, Text, Bild** | Epochentypisch gestaltet (Kupferstich, Lithografie, Fotografie, Zeitungsausschnitt) |
| **Auslöser** | Bedingungen (Datum, Zustand, Zeitgeist, vorherige Ereignisse) und Wahrscheinlichkeit |
| **Optionen** | 2–5 Optionen; jede mit sichtbaren Sofortfolgen und angedeuteten Langzeitfolgen |
| **Reaktionen** | Vorschau, wie Interessengruppen, Parteien und Nachbarn reagieren |
| **Historischer Kompass** | Markiert die historisch gewählte Option (abschaltbar) |
| **Quellen** | Verweis auf Lexikon und Quellenangaben |

**Gestaltungsregeln**

1. **Keine offensichtlich beste Option.** Jede Wahl hat Kosten.
2. **Konsequenzen sind nachvollziehbar** – auch wenn sie später eintreten (Hinweis „Diese Entscheidung wird Folgen haben“ + Eintrag in der Chronik).
3. **Historische Stimmen:** Wo möglich, werden Positionen historischer Akteure zitiert oder paraphrasiert.
4. **Keine Optionen für Massenverbrechen** (siehe [20 Verantwortung](20_verantwortung_und_erinnerungskultur.md)).

## 5. Missionsbäume

### 5.1 Aufbau

- Jede Fokus-Nation hat für jede relevante Epoche einen **Missionsbaum** mit 15–30 Missionen.
- Missionen haben **Bedingungen**, **Belohnungen** (Ansprüche, Modifikatoren, Persönlichkeiten, Ereignisse) und **Abhängigkeiten**.
- Missionsbäume enthalten **Verzweigungen** (z. B. Absolutismus oder Ständekompromiss), die sich gegenseitig ausschließen.
- Generische Bäume für Typen: Geistlicher Staat, Reichsstadt, Grafschaft, Mittelstaat, Land im Bundesstaat.

### 5.3 Beispiel: Königreich Bayern (1806–1871)

Montgelas' Staat (Integration von Franken und Schwaben) → Verfassung von 1818 → Isar-Athen (Kultur unter Ludwig I.) → Ludwigsbahn und Ludwig-Donau-Main-Kanal → Trias-Politik → 1866: die richtige Seite wählen → Reservatrechte sichern → Der Märchenkönig (Schlossbauten: Prestige gegen Schulden)

### 5.4 Beispiel: DDR (1949–1990)

Antifaschistisch-demokratische Ordnung festigen → Aufbau des Sozialismus → Erster Fünfjahrplan → Grenze sichern (Mauer oder Alternative) → Neues Ökonomisches System → Anerkennung durchbrechen → UNO-Mitgliedschaft → Wohnungsbauprogramm → Mikroelektronik → Sport als Visitenkarte → Reform oder Stagnation (ab 1985)

### 5.5 Beispiel: Nordrhein-Westfalen im Ländermodus (1946–2025)

Zusammenwachsen nach der „Operation Marriage“ → Ruhrstatut überwinden → Montanmitbestimmung → Kohlekrise managen → Universitäten im Revier (Ruhr-Universität Bochum 1965) → Bonn als Hauptstadt halten (1991) → Strukturwandel vollenden → Kohleausstieg im Rheinischen Revier → Wir in NRW

## 7. Krisen

Krisen sind **Zustandsautomaten** mit Stufen, Auslösern und Ausgängen. Beispiel *Revolution 1848/49*:

```
 [Vormärz-Druck] ──(Februarrevolution in Paris)──► [Märzunruhen]
        │                                              │
        │                         ┌────────────────────┼──────────────────────┐
        ▼                         ▼                    ▼                      ▼
   (Reformen vorab)        [Märzministerien]    [Barrikadenkampf]     [Militärische
        │                         │                    │               Unterdrückung]
        ▼                         ▼                    ▼                      │
  Krise entschärft      [Nationalversammlung]  [Zugeständnisse         ▼
                                  │             unter Druck]     Radikalisierung,
                                  ▼                    │          Auswanderung
                        [Verfassungskonvent] ◄─────────┘
                                  │
                ┌─────────────────┼────────────────────┐
                ▼                 ▼                    ▼
       [Krone angenommen] [Krone abgelehnt]   [Republikanischer Weg]
                │                 │                    │
                ▼                 ▼                    ▼
     Paulskirchen-Reich   Reichsverfassungs-   Bürgerkrieg mit
     (Krisen mit          kampagne →           ungewissem Ausgang
      Österreich/Russland) Gegenrevolution
```

## 8. Beispielskripte (Chronik-Skript)

### 8.1 Ereignis: Märzforderungen 1848

```text
event maerzrevolution.1 {
    title   = maerzrevolution.1.t      # „Die Märzforderungen“
    desc    = maerzrevolution.1.d      # Volksversammlung in Mannheim, 27. Februar 1848
    picture = volksversammlung
    historical_date = 1848.2.27

    trigger = {
        year >= 1846
        world_has_event_happened = februarrevolution_frankreich
        world_zeitgeist = { liberalismus >= 60 }
        any_owned_location = { pop_consciousness >= 50 }
        has_law = presse_vorzensur
    }
    mean_time_to_happen = { months = 3 }

    option = {                          # Gewähren – Märzministerium berufen
        name = maerzrevolution.1.a
        historical = yes
        change_law = { group = presse_und_medien law = pressefreiheit }
        ig = { id = bildungsbuergertum approval = 4 }
        ig = { id = adel_und_ritterschaft approval = -3 }
        add_legitimacy = 5
        add_authority = -10
        start_journal = revolution_1848
    }
    option = {                          # Zeit gewinnen
        name = maerzrevolution.1.b
        add_authority = -3
        world_revolutionary_pressure = { add = 10 }
    }
    option = {                          # Militär einsetzen
        name = maerzrevolution.1.c
        trigger = { army_loyalty >= 50 }
        ig = { id = militaer approval = 3 }
        add_legitimacy = -10
        trigger_event = { id = maerzrevolution.20 days = 5 }   # Barrikadenkämpfe
    }
}
```

## 9. Chronik und Lexikon

### 9.1 Chronik

- **Automatisch geschriebenes Geschichtsbuch** der Partie, gegliedert nach Epochen und Kapiteln.
- Inhalte: Herrscher und Regierungen, Kriege und Friedensschlüsse, Reformen, Wahlergebnisse, Wirtschaftsdaten, Wendepunkte mit gewählten Optionen, Zitate aus Ereignissen.
- **Vergleich mit der realen Geschichte:** Abweichungsgrad, wichtigste Abweichungen („In Ihrer Geschichte nahm Friedrich Wilhelm IV. die Kaiserkrone an …“).
- **Export** als PDF im Epochenstil – zum Teilen, Vergleichen und für den Unterricht.

### 9.2 Lexikon

- Rund **1.500 Artikel** zu Personen, Orten, Begriffen, Ereignissen, Parteien und Institutionen.
- Geschrieben bzw. geprüft vom Historiker-Team, mit Quellen und weiterführender Literatur.
- Aus jedem Tooltip, Ereignis und Charakterbogen erreichbar.
- Kennzeichnung von **Forschungskontroversen** (z. B. Kriegsschuldfrage 1914, Handlungsspielräume Brünings, Bewertung der Treuhand).
